# Math Quiz 1.0

The initial two-player math quiz interface.

**Repository created:** 2021-08-23  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2021-08-22

## Features and implementation

- Two player-name inputs.
- Styled login layout.

## Technologies

HTML, CSS, Bootstrap, jQuery.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |
| [`style.css`](style.css) | Page styling |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/Math_Quiz_1.0.git
cd Math_Quiz_1.0
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Open the login layout to view the prototype.

## Current status and limitations

No JavaScript game logic or question screen is included.
